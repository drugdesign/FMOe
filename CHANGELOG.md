# Changelog

All notable changes to this project will be documented in this file.

## [0.7.0] - 2025-09-12
### Added
- Direct loading of CPF files from FMODB in **Visualization**.
- List output of atomic charges and fragment charges in **Visualization**.
- Support for all CPF versions registered in FMODB.
- Automatic fragmentation for nucleic acids in **Fragmentation/Merge**.

### Changed
- Updated README and Citation information.
